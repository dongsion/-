# 杯套收藏馆

一个参考移动端截图制作的纯前端杯套收藏馆。适合个人使用，也可以直接复制到 GitHub Pages 发布。

## 使用方式

1. 在 GitHub 新建一个空项目库。
2. 把 `index.html`、`styles.css`、`app.js` 复制进去。
3. 打开 `index.html` 即可运行；如果开启 GitHub Pages，也可以直接通过网页访问。

## 已实现

- 默认馆藏数量为 0，首次打开显示空状态
- 贡献榜默认数量为 0，暂时没有贡献者
- 首页双列/响应式杯套卡片
- 品牌筛选与关键词搜索
- 杯套详情弹窗
- 收藏与取消收藏
- 上传表单、图片预览、本地保存
- 上传图片自动置于统一白色展示底板（不移除原图背景）
- 贡献榜
- 收藏页与清空收藏
- JSON 备份下载
- JSON 恢复：使用备份完整覆盖当前本地数据
- 浏览器 localStorage 数据持久化

## 说明

这是无需后端的自用版本。上传的内容只保存在当前浏览器，换设备或清理浏览器数据后不会自动同步；可以使用首页的“备份”按钮下载 JSON 文件留存。
